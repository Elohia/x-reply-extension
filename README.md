# X 快速回复 · AI 草稿（v0.4.0 · 独立版）

**装一个扩展就能用**：不装 CLI、不装 Python、不要本地服务、不读本地文件。
语料包（341 条真实回复的统计+例句）直接打包在 `src/reply-style.js` 里。

## 为什么这一版不卡

上一版用 `MutationObserver` 监听整页 DOM（还监听了 `data-testid` 属性）。
X 的 DOM 每秒变几百次，回调里还全量扫推文、每条读一次 `innerText`（强制重排）——
主线程被吃满，于是卡。

这一版**完全不监听页面**：

- 没有 MutationObserver
- 不给每条推文注入按钮（注入按钮数实测 = 0）
- 只有一个悬浮按钮（右下角「回」）+ 快捷键 `Alt+R`
- 点的时候才读「你正在看的那条推文」（推文页 URL → 最后鼠标停留的那条 → 视口中心最近的那条）

## 怎么用

1. `chrome://extensions` → 开发人员模式 → 加载本目录
2. 点扩展图标填 API Key（不填走内置模板）
3. **点任意推文的「回复」→ 面板自动弹出**，标题写「回复 @某人」，正文就是那条推文
4. 三条候选：接一句 / 顶一句 / 收一句 → 改数字 → 「填入回复框」
5. 也可以在没点回复时用右下角「回」或 `Alt+R`（取视口中心那条）

## 学习你自己的语气（v0.9.0）

1. 打开你自己的 X 主页（点左侧「个人资料」）
2. 点扩展图标 → **学习我的推文**
3. 插件会自动往下滚、抓 40–80 条你自己的推文，算出：句子中位数、一句话占比、问句占比、表情占比、常用开头，并留 10 条原句
4. 以后生成回复时，这些会作为 few-shot 塞进提示词——**用你的语气写**，不是通用 AI 腔

存在 `chrome.storage.local`，不上传；想重学就再点一次。

## 语料口径（为什么不像 AI 写的）

| 指标 | 真实回复（341 条） |
|:--|:--|
| 长度中位数 | 30 字（P90 94） |
| 一句话占比 | 74% |
| 问句占比 | 9% |
| 带数字占比 | 60% |
| 套话占比 | 2% |

所以默认写陈述句、不条件反射地提问；推文里没有的数字一律留 `【你的数字】`，不编。

## 实测（Chrome 157 · 全新 profile 只装这一份）

```
悬浮按钮        出现（右下角「回」）
注入按钮数      0（没有监听、没有逐条注入）
主线程          10 次求值 10–20ms
面板            3 条候选（接一句 / 顶一句 / 收一句）+ 原文
填入            草稿 24 字 → 回复框 24 字（恰好一份）
候选条          填入后出现在回复框上方
```

## 数字规则（不编造）

- **只用推文里出现过的数字**（420万、4.2%、3 天…）
- 推文里没有数字就用**不含数字的说法**（"我这边试过几次"），不编造、也不留 `【】` 占位
- 三重兜底：提示词约束 → 本地模板改写 → 渲染前清洗（`dePlaceholder`）
- 实测：AI 输出 `hasPlaceholder: false`，且正确引用了推文里的 420万

## 已知问题

- X 的编辑器残留状态会让 `execCommand` 把同一段应用两次 → 写入前先 `selectAll + delete`（已修，实测 24→24）。
- 页面还没加载出推文就点按钮，会提示"没找到推文"。
- 只在 `x.com` / `twitter.com` 注入；不自动发送。
