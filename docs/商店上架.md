# Chrome 商店上架材料

## 名称
X 快速回复 · AI 草稿

## 简短描述（132 字符内）
点推文的「回复」，自动给三条像人说的话：接一句 / 顶一句 / 收一句。语料来自 341 条真实回复统计，不自动发送。

## 详细描述
见 README「怎么用」与「语料口径」两节，可整段粘贴。

## 分类
Productivity / Social & Communication

## 权限说明（审核会问）
| 权限 | 用途 |
|:--|:--|
| `storage` | 保存 API Key、本人语料、计数，全部在本机 |
| `clipboardWrite` | 「复制草稿」按钮 |
| `tabs` | 弹窗需要知道当前标签页才能发「学习我的推文」指令 |
| `scripting` | 老标签页里脚本失效时补注入（不注入其他站点） |
| `host_permissions: x.com, twitter.com` | 读取当前推文、写入回复框 |
| `host_permissions: api.deepseek.com` / `optional https://*/*` | 调用用户自己配置的 AI 接口 |

## 需要的素材
- [ ] 图标 128×128（已有 icons/icon128.png）
- [ ] 截图 1280×800 ×3：候选条 / 面板三条草稿 / 学习我的推文结果
- [ ] 隐私政策 URL（可放 GitHub Pages 或用仓库里的 docs/隐私政策.md 链接）
- [ ] 开发者账号（$5 一次性）

## 上架后能拿到什么
- 真正的**自动更新**（商店后台静默升级，不需要用户点刷新）
- 可分享的安装链接
