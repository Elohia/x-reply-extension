# 推文草稿 · X 快速回复 v0.7.0

> 仓库：https://github.com/Elohia/x-reply-extension
> 配图建议：`tests/out/auto-open.png`（面板自动弹出 + 三条草稿）

## 1｜主推（推荐，配图）

```
点开任意一条推文的「回复」，它会先给我三条：

接一句 / 顶一句 / 收一句。

口径是从 341 条真实中文回复里统计的：中位数 30 字、74% 一句话、只有 9% 是提问。

不自动发，发不发我自己按。

github.com/Elohia/x-reply-extension
```

## 2｜讲洞察（最容易涨互动）

```
做这个插件最有用的一条：真人回复不是提问，是接着对方的话补一个具体的东西。

我统计了 341 条真实回复，问句只占 9%，一句话占 74%。

所以现在三条草稿是「接一句 / 顶一句 / 收一句」，不是「你觉得呢」。

github.com/Elohia/x-reply-extension
```

## 3｜讲踩坑（技术读者爱看）

```
第一版我让它监听整页 DOM。

X 每秒变几百次，回调里还逐条读 innerText，主线程直接打满，一用就卡。

现在只剩一个悬浮按钮，点的时候才读当前那条推文。

教训：别监听 X 的页面。
```

## 4｜一句话版（转发/评论用）

```
开源了一个小东西：X 快速回复。

点推文的「回复」，回复框上方出三条草稿，点一条填进去，剩下的自己改、自己发。

语料 341 条真实回复，不自动发送，不读 cookie。

github.com/Elohia/x-reply-extension
```
