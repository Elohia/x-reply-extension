# 隐私政策 · X 快速回复

最后更新：2026-11-10

## 我们收集什么

**不收集、不上传任何个人数据。** 插件没有服务器，没有任何遥测。

## 数据存在哪里

| 数据 | 位置 | 用途 |
|:--|:--|:--|
| 你的 API Key | 本机 `chrome.storage.local` | 调用你自己配置的 AI 接口 |
| 你的推文语料（「学习我的推文」生成） | 本机 `chrome.storage.local` | 让生成语气贴近你本人 |
| 生成条数计数 | 本机 `chrome.storage.local` | 仅显示 |

卸载插件即清除。

## 会访问哪些网站

- `x.com` / `twitter.com`：读取你正在浏览的推文文本，把回复写进回复框。**不读取 cookie、不读私信、不自动发送。**
- 你配置的 AI 接口（默认 `api.deepseek.com`）：发送推文文本以生成回复草稿。

## 不会做的事

- 不自动发帖、不自动点赞、不自动关注
- 不把任何内容上传到我们自己的服务器（我们没有服务器）
- 不向第三方出售或共享数据
